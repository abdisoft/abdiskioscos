## Descarga e instalación

Descargá la versión adecuada para tu equipo desde la sección de [**Releases**](../../releases/latest).

| Sistema operativo | Archivo a descargar |
|---|---|
| Windows 10/11 (64 bits) | Instalador `.exe` |
| Linux | Archivo `.AppImage` o paquete `.deb` |

Luego ejecutá el archivo descargado y seguí los pasos del instalador.

> La aplicación funciona sin conexión a internet para las tareas diarias. Solo se recomienda conexión para actualizaciones y futuros módulos en línea.

## ¿Qué permite hacer?

- **Ventas rápidas:** cobro por código de barras, precios por lista, promociones, ventas de artículos varios, recargos y presupuestos.
- **Control de stock:** productos, rubros, ingreso de mercadería, movimientos, precios por paquete y alertas de faltantes.
- **Caja:** apertura y cierre, ingresos, egresos, arqueo y reportes de ventas.
- **Clientes y proveedores:** cuenta corriente, historial y datos de contacto.
- **Usuarios y permisos:** roles con accesos diferenciados y restricciones horarias para el punto de venta.
- **Reportes y estadísticas:** ventas por período, producto o vendedor; comisiones, rentabilidad y comparativas.
- **Importación de productos:** carga masiva desde Excel o CSV mediante plantilla.
- **Actualizaciones automáticas:** verifica e instala actualizaciones disponibles de forma segura.

## Requisitos del sistema

- **Windows:** Windows 10 u 11 de 64 bits.
- **Linux:** distribución reciente compatible con AppImage o paquetes `.deb`.
- **Memoria RAM:** 4 GB o más.
- **Espacio libre:** 500 MB recomendados.
- **Pantalla:** resolución mínima de 1100 × 700.
